# SC26 Research Poster Submission Draft

This folder contains a submission-oriented package for SC Research Posters.

## Components

| File | Role |
| --- | --- |
| `poster_draft.tex` / `poster_draft.pdf` | Representative poster draft sized to fit within a 4 ft by 6.5 ft board |
| `planned_updates.md` | Final-version update statement |
| `sc26_summary.tex` / `sc26_summary.pdf` | IEEE-format 800-word summary draft, excluding references |
| `artifact_description_appendix.tex` / `.pdf` | Optional artifact-description appendix draft |
| `figures/` | Visual assets used by both the summary and poster |

## Compile

```bash
cd /Users/yifn/Documents/sc26-cdc-deltaai/paper/submission
make
```

The summary is intentionally concise and poster-oriented. The longer paper-style draft remains one directory up as `../main.tex`.
